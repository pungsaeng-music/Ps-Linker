풍생 링커 (Pungsaeng Linker)


풍생고등학교 학생들을 위한 편리한 링크 모음 웹사이트입니다.


📌 프로젝트 소개


자주 사용하는 학교 관련 웹사이트와 서비스를 한곳에서 빠르게 이용할 수 있도록 제작한 웹 프로젝트입니다.


✨ 주요 기능




학교 관련 사이트 바로가기


직관적이고 간편한 사용자 인터페이스


모바일 및 PC 반응형 지원


빠른 페이지 접근




🛠️ 사용 기술




HTML


CSS


JavaScript


GitHub


GitHub Actions




🚀 배포


GitHub 저장소를 통해 소스 코드를 관리하며, GitHub Actions를 이용한 자동 배포를 지원하도록 구성합니다.
